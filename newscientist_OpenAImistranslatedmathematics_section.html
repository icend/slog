3. 整句中文释义

OpenAI 在其纳维-斯托克斯方程证明中将数学"误译"成了代码

一个数学家团队声称，OpenAI 在发布纳维-斯托克斯问题的证明时似乎犯了一个细微的错误。这个错误并不意味着证明本身有误，也不意味着 OpenAI 没有正确解决该问题，但它确实让人们不得不质疑：AI 模型生成的数学结果是否总能信赖？

剑桥大学的安德斯·汉森表示："所有这些大语言模型生成的证明，最终都必须由人来阅读，这给数学家带来了巨大的额外负担。"

9月8日，OpenAI 宣布它找到了纳维-斯托克斯问题的解决方案——这是数学界最著名的未解难题之一。该公司发布了两个版本的证明：一个用"自然语言"撰写，即英语与数学符号的结合，如同人类数学家所写的那样；另一个用计算机代码 Lean 编写。Lean 证明旨在作为自然语言版本的形式化，让计算机能够机械地验证其所有逻辑命题是否成立。但汉森及其团队表示，问题在于：这两个版本并不一致。

该团队成员、同样来自剑桥大学的法比安·塞尔切利说："这个形式化过程试图取代同行评审。同行评审意味着有人亲自审阅证明。但我们在这篇论文中表明，使用这种 AI 自动形式化无法起到同样的作用。"

OpenAI 722 篇新论文中最有趣的数学发现

需要明确的是，研究人员并不是说 OpenAI 未能解决纳维-斯托克斯问题。自然语言证明和 Lean 证明完全有可能都给出了正确解答，正如勾股定理已有数百种有效证明一样。相反，他们指出的问题更为微妙：OpenAI 的模型在转换为 Lean 时发生了"误译"。

汉森说："我们并不是说自然语言证明是错的，我们也没有说它是对的。"问题在于，OpenAI 将两个证明呈现为完全相同的版本，并在 Github 上声明："本仓库包含[论文]《纳维-斯托克斯方程的有限时间爆破》中所述结果的 Lean 4 形式化。"

汉森解释说，这种误译的产生是因为 AI 必须生成一个能够"编译通过"的 Lean 证明，即计算机代码完全自洽、不报错。如果在自动形式化过程中，AI 发现某段证明无法编译，它就会试图寻找变通方案，哪怕这意味着偏离自然语言版本的原文。

OpenAI 甩出 722 篇数学论文——现在它必须收拾这个烂摊子

该团队的具体指控集中在证明中一个名为"引理 8.6"的部分。在自然语言证明中，这一部分的某个方程要求某一数值小于 m+4，其中 m 为整数。而在 Lean 证明中，对应的值被要求小于 m+5，这在数学上更弱。

要理解原因，想象一下被要求解方程 x+3=6，答案是 x=3。你可以写一个证明说明 x 必须小于 4，也可以写一个证明说明 x 必须小于 5。这两个都是完全正确的数学命题，但它们说的是不同的事情。后一个证明允许 x 有更多可能的取值，因此在数学上更弱。

OpenAI 向《新科学家》表示，它已注意到自然语言证明与 Lean 代码之间存在不一致，但这并不意味着任何一个证明无效。公司表示，将在发现错误时纠正自然语言证明中的任何问题，并将继续对本周发布的 722 篇数学论文进行形式化工作——其中只有一部分配有 Lean 证明，而这些 Lean 证明本身也尚未经过人工检查。

发现这一分歧的过程颇为超现实：团队让 ChatGPT 寻找自然语言证明与 Lean 证明之间可能存在的差异，然后再人工核查。ChatGPT 提出的许多差异经检查后结果是一致的。汉森说："手动排查所有这些东西简直是一场噩梦。"

整个团队花了大约两周时间才确认了一处真正的差异，而 OpenAI 称其智能体仅用了 88 小时就生成了这些证明。伦敦国王学院的团队成员亚历山大·巴斯图尼斯说："OpenAI 吹嘘他们能多快出结果，但那只是整个过程的一部分。"

要让数学家信任这些结果，回答"AI 模型能否准确地自动形式化数学"这一问题至关重要。汉森及其团队已经证明，ChatGPT 完全可能生成一个与原始自然语言证明不匹配的 Lean 版本，而 AI 在此过程中悄然改变了逻辑论证以掩盖错误。汉森说："它是在想帮我，但这么做反而帮了倒忙。"

订阅者专属通讯

如果这种情况发生在一个冗长复杂的证明上，任何人若不详细对比两个版本，都很难发现。而 OpenAI 刚发布的这批 722 篇论文，让这个问题变得更加紧迫。汉森说："如果我们以为'这些现在都是对的了，我们要做的就是读论文'，那就危险了。做科学的意义在于让人类理解世界是如何运作的，这样我们才能做出有依据的决策。如果失去了这种理解，我们还在做什么？"

伦敦帝国理工学院的凯文·巴扎德指出，在这类讨论中，区分定理的陈述和它的证明非常重要。例如，著名的费马大定理的陈述是：对于正整数 a、b、c 和 n，只有当 n 为 1 或 2 时，aⁿ+bⁿ=cⁿ 才成立。这个陈述很容易转换为 Lean 并轻松验证。一旦你确信 Lean 中的陈述是正确的，且该陈述的证明编译通过，你就可以确信证明是真的。

但正如汉森及其团队指出的那样，这完全不能说明以 PDF 文档形式发布的自然语言证明是否正确。巴扎德说："我相信纳维-斯托克斯问题已经得到了正确的解决，但我远没有那么确信 PDF 中描述的证明是正确的。"

汉森表示，他希望 OpenAI 能"非常认真地"对待该团队的工作，并在开发可靠的自动形式化技术方面做出更多努力。"我们有解决方案了吗？还没有。有可能以可控的方式做到这一点吗？会有的，但最佳和最终的方法目前完全未知。"
